# Notify CLI Pricing & Licensing

Notify CLI is free, open-source software maintained by SpaceCorps.

## CLI Licensing
- **License**: MIT License.

- **Source Code**: [GitHub](https://github.com/SpaceCorps/Notify-Cli)

## External Services
Notify CLI connects directly to third-party notification services configured by the user:
- **Slack**: Incoming Webhooks are available on both free and paid Slack workspaces at no additional cost.
- **Gmail**: Gmail API access is available under Google Cloud Platform's standard free tier quotas.
- **Desktop & Message Box**: Operates 100% locally with zero external network connectivity or fees.
